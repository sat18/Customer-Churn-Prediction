# Customer Churn Prediction

## Overview
This project focuses on analyzing customer behavior to identify churn patterns and predict the likelihood of customer churn. The objective is to support data-driven decision-making by combining structured data analysis, machine learning, and interactive visualization.

## Problem Statement
Customer churn is a critical business challenge. By identifying customers who are likely to churn, businesses can take proactive steps to improve retention and reduce revenue loss.

## Dataset
- The dataset contains customer demographic, account, and usage information.
- Includes features such as tenure, contract type, monthly charges, and payment method.
- Data preprocessing was performed to handle missing values and ensure consistency.

## Approach
- Performed data cleaning and validation to ensure accuracy.
- Conducted exploratory data analysis (EDA) to identify churn trends and patterns.
- Built a supervised machine learning model to predict churn probability.
- Evaluated model performance using standard metrics.
- Developed an interactive dashboard for result visualization.

## Tools & Technologies
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  
- Streamlit  

## Key Features
- End-to-end data analysis workflow  
- Churn prediction with probability-based output  
- Interactive dashboard for business insights  
- Focus on data accuracy, validation, and interpretability  

## Results
- The model provides reliable churn predictions with good performance metrics.
- Insights highlight key churn drivers such as tenure, contract type, and monthly charges.
